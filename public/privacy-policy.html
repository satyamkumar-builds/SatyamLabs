SatyamLabs — Privacy Policy

Effective Date: November 3, 2026 · Version 3.1.4
100% Privacy Focused · No Data Collection

1. Overview

SatyamLabs ("we", "our", or "the App"), developed by Satyam Kumar, is a mobile-first and web-based code studio, editor, and multi-language compiler environment. We deeply respect your privacy. This Privacy Policy explains our commitment to keeping your data secure and completely private.

2. Data Collection and Usage

We do NOT collect, harvest, store, or share any personal information.

  • No Account Required: You do not need to register, provide an email, or sign in to use SatyamLabs.
  • No Analytics or Tracking: We do not include third-party tracking libraries, advertising SDKs, or user behavior analytics.
  • No Location or Device Tracking: The App does not access your GPS location, contacts, camera, or microphone.

3. Code and Workspace Storage

All source code files, folders, templates, settings, and workspace data you create in SatyamLabs are stored strictly locally on your device (using device local storage / internal app storage). Your proprietary code is never sent to our servers or stored in any remote database.

4. Network Permissions & Compilation

SatyamLabs includes both offline and cloud compilation capabilities:

  • In-Device Offline Engine: By default, execution of C, C++, Java, Python, and Web code can run entirely offline on your phone or browser without sending any data over the internet.
  • Optional Cloud Compilers: If you choose to execute code online, the code snippet is transmitted securely over HTTPS solely to compile the program and return standard output/errors. No code is retained or tied to your identity.

5. Children's Privacy

SatyamLabs is designed for learners, developers, and students of all ages. Because we do not collect any personal data whatsoever, our application complies fully with COPPA (Children's Online Privacy Protection Act) and the General Data Protection Regulation (GDPR).

6. Changes to This Privacy Policy

Any updates to this policy will be posted on this page. We encourage users to periodically review this page for any updates.
